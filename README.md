# Пепельная яма (Cinder Pit)

Bitecs, three.js, React, Vite.

Играть в браузере https://cinder-pit.golub.network

Стартовая версия игры. Дальше мы дописываем ее по шагам вместе с ИИ-агентом. Ассеты, интерфейс, ядро ECS, камера и управление уже готовы.

```
npm install
npm run dev        # игра
npm run typecheck  # типы
npm test           # тесты
npm run map        # карта кода
npm run diagrams   # схема кадра в браузере
npm run build      # сборка в dist
```

## Папки

```
src/
  game/              логика игры, не знает про браузер
    arena/           уровень: сетка клеток, генерация пещер шумом
    config/          весь баланс, только данные
    ecs/             мир, запросы, события, порты
      components/    компоненты, только данные
      systems/       кадр по порядку в index.ts, по папке на домен
        core/        время, соседи, срок жизни, удаление
        player/      взгляд, ходьба и посмертный дрейф игрока
        physics/     движение, толкотня, парение, гравитация
        spawn/       волны и стаи кольцом, возврат и удаление врагов
        enemy/       погоня по полю путей, перезарядка
        combat/      цель, касание, урон, смерть врагов и героя, трупы
        weapons/     выстрел оружия по кнопке
        projectile/  полет снарядов, стены, попадания, взрывы
        arena/       сдвиг бесконечной арены, поле путей до игрока
        view/        камера, туман биома, уровень и все, что рисует
    entities/        сборка сущностей из компонентов
    weapons/         логика выстрела: дробь, разброс, отдача
    math/            углы, случайные числа, шум, цвет
    physics/         пространственный хеш, столкновения тела
    progression/     сохранение
  platform/          браузер
    assets/          загрузка текстур и спрайтов
    input/           клавиатура, мышь, тач
    render/          three.js, сцена и эффекты
    storage/         сохранение на диск
  app/               собирает мир, подает порты, фазы игры
  ui/                React, с игрой только через app
    hud/             интерфейс поверх игры
tests/               тесты без браузера
```

Связи систем и данных смотреть в карте кода.
